Findly 图标集预览

全部为矢量 SVG · 由 F-icon-transparent.svg 派生 · 原始图形路径未做任何重绘

1. 主图标（含阴影完整版 / 扁平简化版）

master 用于 ≥96px 的展示场景；flat 去除投影，用于 ≤64px 及禁止滤镜的渲染环境。

2. 平台 / 应用场景变体

circle 用于社交头像；maskable 为 PWA 可遮罩图标（红色虚线为安全区）；apple-touch 为全出血方形（由系统自行裁圆角）。

3. 无底图形 Glyph（透明底）

glyph 原配色用于深色 / 品牌色背景；glyph-teal 为浅色背景重配色版；mono 为单色剪影（印刷、刻字、水印）。

4. 小尺寸表现（实际像素尺寸）

16–64px 使用扁平版（无投影糊成一团的问题）。

5. SVG Sprite（网页内联复用）

sprite.svg 内含 5 个 symbol：findly-icon / findly-icon-flat / findly-glyph / findly-glyph-teal / findly-mono（mono 使用 currentColor，可随文字颜色变化）。用法： <svg width="48"><use href="assets/sprite.svg#findly-glyph-teal"/></svg>

6. 文件清单

文件用途

master/icon-flat.svg扁平主图标（无滤镜）——兼容受限渲染器
